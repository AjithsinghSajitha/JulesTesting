# UI/UX Goals and Philosophy

The User Interface (UI) and User Experience (UX) of "Dynasty of the Voiceless" are paramount to its success. The game features two distinct modes of play—a high-level RTS view and an immersive first-person mode—and the UI must seamlessly support both without compromising either. Our design philosophy is built on three core pillars: **Immersion, Clarity, and Scalability.**

## 1. Pillar 1: Immersion First

The primary goal is to make the player feel like they are in the world of Veridian, not playing a video game. The UI should, whenever possible, recede into the background or be integrated directly into the game world (diegetic UI).

*   **Minimalism in Possession Mode:** In the first-person view, the traditional HUD (Heads-Up Display) will be almost non-existent. Health status will be shown through screen effects (blood splatter, desaturation, heavy breathing sounds). Quest information will be gleaned from conversations and the environment, not a checklist on the screen.
*   **Tactile and Thematic UI:** Menus, maps, and icons should adhere to the "Painterly Realism" art style. Maps should look like parchment, menus should have wood or stone textures, and icons should be simple, hand-drawn symbols. The UI should feel like a physical part of the world.
*   **Contextual Awareness:** UI elements should only appear when they are needed. A compass might only appear when the player presses a "navigation" key. Interaction prompts should be subtle and integrated into the object being looked at.

## 2. Pillar 2: Clarity and Intuitiveness

While the UI should be immersive, it must also be easy to understand and use. The complexity of the game's simulation should be presented to the player in a clear and digestible way.

*   **Information Hierarchy:** The most important information should always be the easiest to see. In the RTS view, a faction's food supply is more critical than the name of a specific peasant, and the UI should reflect that priority.
*   **Consistent Language:** Icons and terminology should be consistent across both game modes. The icon for "wood" should be the same in the RTS resource panel and in a character's inventory.
*   **Tooltips on Demand:** The game has deep, complex systems. To avoid overwhelming the player, detailed information will be hidden behind tooltips. A player can see their basic resource income, but hovering over the "Income" panel will reveal a detailed breakdown of all sources and expenses. This is our "simple at a glance, complex on demand" approach.

## 3. Pillar 3: Scalability and Mode-Switching

The UI must fluidly transition between the macro-level RTS mode and the micro-level Possession mode. The player should feel like they are using two sides of the same interface, not two different programs.

*   **Seamless Zoom:** The transition from Overworld View to Possession Mode should be a single, seamless camera zoom with no loading screens. As the camera zooms in, the RTS UI elements (like faction banners and resource counters) should fade out, while the minimal first-person UI fades in.
*   **RTS UI (The Overmind):** The UI in this mode can be more data-rich. It will feature non-diegetic panels for managing resources, diplomacy, and military strategy. This is the "brain" of the game, and the UI should provide all the necessary information for making informed decisions.
*   **Possession UI (The Mortal):** The UI in this mode is minimal and focused on the immediate needs and senses of the character. It will feature a simple interaction dot, contextual prompts, and very little else on screen by default.

By adhering to these three pillars, we will create a UI that is powerful enough to manage a complex simulation, yet elegant and unobtrusive enough to allow the player to lose themselves completely in the world of Veridian.
