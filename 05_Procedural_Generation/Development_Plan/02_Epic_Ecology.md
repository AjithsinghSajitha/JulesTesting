# Epic 2: Ecology Simulation

**Epic Goal:** To populate the procedurally generated terrain with a rich and believable ecosystem of flora and fauna. This system will place plants and spawn animals based on biome rules, and give the animals basic, believable behaviors.

---

## Sprint 1: Foundational Flora Placement

**Sprint Goal:** To create a system that can procedurally place large amounts of foliage (trees, bushes, rocks) across the terrain in a performant and natural-looking way.

*   **User Story 1.1: Flora Data Resource**
    *   **As a designer,** I need to define different types of flora using a custom `FloraData` resource script (`flora_data.gd`).
    *   **Data Points:** The resource should include the `Mesh` to be used, valid biomes for placement, placement density (per square kilometer), and grouping/clustering parameters.
    *   **Acceptance Criteria:** I can create resources like `pine_tree.tres` and `oak_tree.tres`, defining their 3D models and where they should appear.

*   **User Story 1.2: Placement Algorithm**
    *   **As a developer,** I need to create a `FloraManager` script that reads the biome map data. For a given area, it should use a Poisson Disk Sampling algorithm (or a similar "blue noise" pattern) to determine the placement positions for flora.
    *   **Acceptance Criteria:** The placement algorithm generates positions that are random but maintain a minimum distance, avoiding grid-like patterns and unnatural clumping. The density of points should match the `FloraData` for that biome.

*   **User Story 1.3: Performant Instancing**
    *   **As a developer,** I need to use `MultiMeshInstance3D` nodes to render the flora. The `FloraManager` will populate the `MultiMesh` with the transforms generated by the placement algorithm.
    *   **Acceptance Criteria:** Thousands of trees and rocks can be rendered on the terrain with a minimal number of draw calls, ensuring high performance. Each instance in the `MultiMesh` can have slight random variations in rotation and scale.

## Sprint 2: Fauna Spawning System

**Sprint Goal:** To create a dynamic system that spawns and despawns animals in the world around the player, based on biome and population rules. This avoids simulating every animal on the continent at all times.

*   **User Story 2.1: Fauna Data Resource**
    *   **As a designer,** I need a `FaunaData` resource script (`fauna_data.gd`) to define animal types.
    *   **Data Points:** The resource should include the animal's `PackedScene`, home biome, typical herd/pack size, and whether it is prey or predator.
    *   **Acceptance Criteria:** I can create resources like `deer.tres` and `wolf.tres` that link to their respective character scenes and define their ecological niche.

*   **User Story 2.2: The "Bubble" Spawner**
    *   **As a developer,** I need to create a `FaunaManager` node. This manager will track the player's position and define a "spawning bubble" (e.g., a 500-meter radius) around them.
    *   **Acceptance Criteria:** The manager can identify which areas of the world are currently inside the player's bubble.

*   **User Story 2.3: Biome-Based Spawning**
    *   **As a developer,** the `FaunaManager` needs to periodically check the biomes within the player's bubble and spawn animal groups according to the rules in the `FaunaData` resources. It must also despawn animals that are no longer in the bubble for a certain amount of time.
    *   **Acceptance Criteria:** When a player walks from a forest into a tundra, deer will despawn and be replaced by newly spawned wolves or mountain goats. The total animal population remains stable.

## Sprint 3: Basic Animal AI and Behavior

**Sprint Goal:** To implement simple, believable AI for the spawned fauna, making them react to the world and each other.

*   **User Story 3.1: Navigation Mesh Integration**
    *   **As a developer,** I need to ensure the procedural terrain generation (from Epic 1) also generates a `NavigationMesh` that AI-controlled characters can use for pathfinding.
    *   **Acceptance Criteria:** The `NavigationServer3D` has a valid navigation mesh for the generated terrain. A debug view can confirm that the navmesh is correct.

*   **User Story 3.2: Prey Behavior**
    *   **As a developer,** I need to create a simple state machine for prey animals (e.g., deer). The states should be:
        1.  **Wandering:** Move to random reachable points on the navmesh.
        2.  **Grazing:** Periodically stop moving and play a grazing animation.
        3.  **Fleeing:** If a predator or player comes within a certain radius, run directly away from the threat at high speed.
    *   **Acceptance Criteria:** Deer can be seen wandering naturally and will run away when approached.

*   **User Story 3.3: Predator Behavior**
    *   **As a developer,** I need to create a simple state machine for predator animals (e.g., wolves). The states should be:
        1.  **Patrolling:** Move between random points in a defined territory.
        2.  **Stalking:** If prey enters its detection radius, move towards it slowly.
        3.  **Chasing:** When close enough, run directly at the prey to "attack" (for now, a simple collision check is fine).
    *   **Acceptance Criteria:** Wolves will patrol an area and will actively hunt and chase any nearby deer.

---

## Sprint 4: Ecology-Based Resources

**Sprint Goal:** To connect the ecology systems to the resource system, allowing players to gather materials from plants and animals.

*   **User Story 4.1: Collectible Flora**
    *   **As a developer,** I need to implement a system where specific flora instances (e.g., a glowing mushroom) can be interacted with by the player.
    *   **Acceptance Criteria:** When the player looks at a collectible plant and presses the interact button, the plant is removed (or changes state) and a corresponding resource item is added to the player's inventory.

*   **User Story 4.2: Fauna Resource Drops**
    *   **As a developer,** I need to add a "loot table" to the `FaunaData` resource that defines which resource items an animal drops upon death.
    *   **Acceptance Criteria:** When an animal (e.g., a deer) is killed, its body can be interacted with to retrieve items like `Venison` and `Pelt`.
